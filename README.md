Neon Vice Cover Studio — an offline web app that turns any photo and caption into multi-panel GTA 6-style cover art: 8 poster layouts, 8 sunset/neon colour grades, per-panel crop and positioning for up to 4 photos, editable gradient title with neon subtitle, and one-click PNG export in 7 post sizes (1080×1080, 1080×1350, 1920×1080, 1080×1920 story, 2048×1152, 1200×630, 1080×566). Photos never leave the machine; the app makes zero network requests.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a desktop browser, add photos (or load the samples), pick a layout and grade, edit the caption, and hit Export PNG.
